# Marketplenum

Live site: https://marketplenum.com — Advertising platform and Marketplace automation.

- Static site on GitHub Pages: plain HTML, CSS and JavaScript, no build step. Pushing to `main` publishes it.
- The apps are built and tested on the test site (solvephantasma.com, repo `Giorgilomidze/Phantasma`) and released
  here as unchanged copies. Do not edit released folders or the released `styles.css` / `career.js` here.
- Same backend (Supabase project) as solvephantasma.com.
